# AKTU SGPA & CGPA Calculator

Calculate SGPA, CGPA and percentage for AKTU students.

- Subject-wise mode: add subjects, credits and grades for each semester
- Quick mode: enter SGPA + credits per semester to get CGPA
- Percentage = (CGPA × 10) − 7.5
- Editable grade scale, saves your data in the browser
- Works on mobile, light and dark mode

**Tech:** HTML, CSS, JavaScript (no frameworks)
